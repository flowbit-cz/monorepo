# @dertour/testing

Helpers for Vitest component and integration tests.

| Helper                                  | What                                                                    |
| --------------------------------------- | ----------------------------------------------------------------------- |
| `renderWithProviders(ui, { messages })` | renders with next-intl + TanStack Query, returns `user` (user-event)    |
| `setupMswServer(handlers)`              | MSW server for the test file, resets overrides, fails on unmocked calls |
| `expectNoA11yViolations(container?)`    | axe WCAG 2.1 A/AA check (contrast is checked in E2E)                    |

API mocks come from `@dertour/api/mocks` (generated by Orval + demo data).
