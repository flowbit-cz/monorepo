# @dertour/api

Clients for backend APIs, **generated by [Orval](https://orval.dev) from OpenAPI**. Don't write API calls by hand.

## Where the spec comes from

Each service has an env variable with its OpenAPI URL (`.env`, see `.env.example`):

```
OPENAPI_OFFERS_URL=https://<backend-host>/v3/api-docs
```

When the variable is missing, Orval uses the demo spec in `example/`, so the template and CI work without a backend.
`pnpm generate` runs before every `dev`, `build`, `lint`, `typecheck` and `test` (Turbo `generate` task). The output
goes to `src/generated/` and is not committed.

## What gets generated (per service)

| Import                      | What                                   | Use in                                            |
| --------------------------- | -------------------------------------- | ------------------------------------------------- |
| `@dertour/api/offers`       | plain async functions (`listOffers`)   | Server Components, route handlers, server actions |
| `@dertour/api/offers/query` | TanStack Query hooks (`useListOffers`) | Client Components                                 |
| `@dertour/api/offers/zod`   | zod schemas of params/responses        | validation, forms, tests                          |
| `@dertour/api/offers/model` | TypeScript types                       | everywhere                                        |
| `@dertour/api/mocks`        | MSW handlers with faker data (seeded)  | tests, local dev, E2E                             |

Every call goes through `src/mutator/customFetch.ts`: base URL, headers, timeout and `ApiError` for non-2xx.

**Mock mode:** with `API_MOCKING=enabled`, server-side calls are answered in-process by the MSW handlers
(`src/mocks/mockFetch.ts`), with no backend and no patched global fetch. Browser calls go to the app's
`/api/mock/*` route, which uses the same handlers.
Base URL: `API_BASE_URL` (server) or `NEXT_PUBLIC_API_BASE_URL` (browser), or `configureApi({ ... })`.

## Adding a service

1. Add it to `SERVICES` in `orval.config.ts` (env variable + optional demo spec) and to `export default`.
2. Add the `exports` entries in `package.json` and the mock handlers to `src/mocks/handlers.ts`.
3. `pnpm generate`.
