# template

Template Next.js app of the DERTOUR monorepo. A new app starts as a copy of this folder. A Claude skill will
automate that later.

```bash
cp .env.example .env    # mocks are on by default, no backend needed
pnpm dev                # http://localhost:3000
pnpm test               # unit + component + integration (Vitest)
pnpm test:e2e           # Playwright against mocked APIs
```

## Structure

```
src/
├── app/                 # ROUTING ONLY: pages import a module component and render it
│   ├── [locale]/…       # all pages (next-intl, de default without prefix, /en, /cs)
│   └── api/             # health check, mock route (API_MOCKING)
├── config/appData.ts    # name, URLs, locales: never hard-code these
├── i18n/                # routing, request config, messages (shared + global + per module)
├── styles/global.css    # Tailwind v4 + tokens + design system
├── components/          # app-wide components only (layout, providers, integrations)
├── lib/                 # env validation, logger, mock API
├── modules/             # everything domain-specific, one folder per domain
│   ├── home/
│   └── offers/          # reference module, read its README
├── test/                # test helpers (renderApp)
└── proxy.ts             # Next 16 proxy: locale detection
e2e/                     # Playwright flows
```

## Data

The backend owns data and e-mails. The app only reads APIs through clients generated by Orval (`@dertour/api`).
Calls run on the server where possible (Server Components, cached with `next.revalidate`), and in the browser
only for interactive bits (React Query hooks).

`API_MOCKING=enabled` answers every call from MSW: on the server in-process (`@dertour/api` mutator), in the
browser through `/api/mock/*`. The data is the realistic demo set in `@dertour/api/mocks/demo`.

## Env

See `.env.example`. Validated at startup by `src/lib/env.ts`.

## Docker

```bash
docker build -f apps/template/Dockerfile -t dertour/template .   # from the monorepo root
docker run -p 3000:3000 -e API_BASE_URL=… -e NEXT_PUBLIC_SITE_URL=… dertour/template
```
